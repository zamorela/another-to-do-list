# Список задач

Тестовое задание ZalogHub: Junior Frontend Developer (React + TypeScript).

Короткий список задач на React и TypeScript. Сервер не нужен: список остаётся в `localStorage` после обновления страницы.

## Запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Приложение откроется по адресу http://localhost:5173.

```bash
npm test
npm run build
npm run preview
```

`npm test` проверяет добавление, пустой ввод, переключение, удаление, фильтры и чтение `localStorage`. `npm run preview` показывает собранную версию.

## Что работает

- добавление задачи через поле и кнопку «Добавить», в том числе по Enter;
- пустой текст и строка из одних пробелов не добавляются;
- переключение между выполненной и активной;
- удаление;
- фильтры: все, активные, выполненные;
- сохранение в `localStorage` и восстановление после перезагрузки;
- выполненные задачи зачёркнуты и отмечены.

## Как устроено

Операции над списком — чистые функции, отдельно от интерфейса. Запись в `localStorage` происходит в момент изменения. При чтении проверяется форма данных: битые записи отбрасываются, приложение из-за них не падает. Список в другой вкладке того же браузера обновляется сам.

## Время

Около 60 минут.
